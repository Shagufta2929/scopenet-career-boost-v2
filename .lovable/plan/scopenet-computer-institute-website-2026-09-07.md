# Scopenet Computer Institute Website

## Build
- Create a polished single-page institute website with a sticky responsive navigation, two-column education-focused hero, trust highlights, courses, categories, about, benefits, testimonials, FAQ, contact, CTA, and footer.
- Use a deep navy, bright blue, white, and pale blue-gray design system with professional typography, restrained gradients, soft shadows, accessible focus states, and subtle motion.
- Keep every provided course in a reusable data structure, preserving the exact durations and fees and clearly marking unknown information.

## Enquiry Experience
- Add enquiry actions to every course card and prominent calls to action throughout the page.
- Open an accessible course-details and enquiry modal with the selected course pre-filled.
- Add a full enquiry section with client-side validation and a polished success state; submission will remain frontend-only so a real integration can be connected later.
- Add a mobile-friendly floating enquiry control without inventing a WhatsApp number.

## Content Integrity
- Use only the supplied institute copy and course information.
- Keep contact details, map, and student reviews as clearly labeled editable placeholders.
- Avoid claims about accreditation, placements, experience, student counts, or achievements.

## Quality Checks
- Add route-specific search and social metadata.
- Verify responsive layouts, menus, accordions, forms, modal behavior, keyboard focus, and visual rendering on desktop and mobile.
