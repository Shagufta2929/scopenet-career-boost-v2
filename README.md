# Scopenet Gateway

Create a modern, attractive and professional website for an educational institute called:

SCOPENET COMPUTER INSTITUTE

The website should feel like a trustworthy, modern computer training institute. It should be designed mainly to attract students and generate enquiries.

IMPORTANT:

Do not make the website look like a generic AI/template website.

Use a premium modern education + technology aesthetic with clean spacing, professional typography, attractive cards, subtle animations and strong call-to-action buttons.
